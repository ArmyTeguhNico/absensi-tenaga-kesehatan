## 💡 **TIPS KUSTOMISASI:**

### **Ganti Warna Gradient:**
Edit file `login-style.css`:
```css
.bg-gradient {
  background: linear-gradient(135deg, 
    #YOUR_COLOR_1 0%, 
    #YOUR_COLOR_2 25%, 
    #YOUR_COLOR_3 50%, 
    #YOUR_COLOR_4 75%, 
    #YOUR_COLOR_5 100%
  );
}
```

### **Ganti Animasi Speed:**
```css
/* Lebih cepat */
animation: gradientShift 10s ease infinite;

/* Lebih lambat */
animation: gradientShift 20s ease infinite;
```

### **Matikan Particles (Kalau Terlalu Ramai):**
```css
.particles {
  display: none;
}
```

### **Ganti Logo Icon:**
Edit `index.html`:
```html
<i class="fas fa-hospital-user"></i>
<!-- Ganti dengan icon lain, contoh: -->
<i class="fas fa-user-md"></i>
<i class="fas fa-heartbeat"></i>
<i class="fas fa-stethoscope"></i>
```

## 🐛 **TROUBLESHOOTING:**

### **Animasi Tidak Smooth:**
- Update browser ke versi terbaru
- Check GPU acceleration aktif
- Tutup tab lain yang berat

### **Glass Effect Tidak Muncul:**
- Safari < 14: Tidak support backdrop-filter
- Solusi: Fallback ke background solid

### **Particles Terlalu Banyak (Lag):**
Edit `index.html`, kurangi jumlah particle:
```html
<div class="particles">
  <div class="particle"></div>
  <div class="particle"></div>
  <div class="particle"></div>
  <!-- Hapus yang lain -->
</div>
```
